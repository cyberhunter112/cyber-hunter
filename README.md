# CYBER-HUNTER v2.0
By Ahmad Mustapha Aliyu
A bash-based reconnaissance tool for ethical hackers.
## Features
- Ping sweep (find alive hosts)
- Quick port scanner (22,80,443,445,8080)
- Colored output (GREEN=alive, RED=dead)
- Logging to alive.txt
- Quick scan mode: ./cyber-hunter-v1.sh
## Usage
./cyber-hunter-v1.sh
./cyber-hunter-v1.sh 192.168.177.2
